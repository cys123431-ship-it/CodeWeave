# 통합 교육과정 로드맵 (초안)

> 아래 장 구성은 최종 목차가 아닙니다. 두 교재의 전체 내용 분석과 주제 매핑을 거쳐 확정해야 합니다.

| 단계 | 주제 | 목표 |
|---|---|---|
| A | C 기초 | 개발 환경, 프로그램의 구성, 입력/출력, 자료형, 연산, 조건·반복 |
| B | C 핵심 | 함수, 배열, 문자열, 포인터, 구조체, 공용체/열거형, 동적 메모리 |
| C | C 심화 | 전처리기, 분할 컴파일, 파일 I/O, 오류 처리, 표준 라이브러리 |
| D | 자료구조 (C) | 배열·리스트·스택·큐·트리·해시·그래프, 구현과 경계 조건 |
| E | 알고리즘 (C) | 복잡도, 탐색·정렬·재귀·분할 정복·탐욕·동적 계획·그래프 |
| F | Rust 기초 | 도구, 변수, 자료형, 함수, 소유권·빌림·참조, 오류 처리 |
| G | Rust 응용 | 컬렉션, 제네릭, 트레이트, 패턴 매칭, 모듈·테스트 |
| H | Rust로 재구현 | C 자료구조·알고리즘 재구현 및 타입·메모리 안전성 비교 |
| I | 종합 프로젝트 | 명세 분석 → 테스트 설계 → C/Rust 구현 → 검증·개선 |

## 퀴즈 및 코딩 문제 정책

- **Concept Check:** 2~5문항 짧은 퀴즈, 직접 판단하는 문제
- **Concept Exercise:** 해당 단원에 대한 작은 코드 작성 문제와 공개된 예시
- **Practice Exercise:** 단원 복합 문제와 여러 입력·경계값 자동 테스트
- **Challenge:** 스스로 자료구조·알고리즘 설계/구현, 난도 별 학습 목표
- **Capstone:** 새로 배운 내용을 묶어 사용하는 완성형 프로젝트

## 시제품의 구현 범위

첫 배포에는 C 5개 샘플, Rust 1개, 자료구조 1개, 알고리즘 1개만 작성되어 있음. 대규모 본문/문제 생성은 별도 후속 작업 필요.

현재 진도 화면은 이론 읽기, 퀴즈 통과, C 실습 통과, 복습 필요, 전체 숙달을 서로 다른 상태로 계산한다. 이는 교육과정 완성도를 뜻하지 않으며, 자동 채점이 없는 트랙은 실습·숙달을 완료로 표시하지 않는다.
