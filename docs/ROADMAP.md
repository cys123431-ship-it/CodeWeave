## 퀴즈 및 코딩 문제 정책

- **Concept Check:** 2~5문항 짧은 퀴즈, 직접 판단하는 문제
- **Concept Exercise:** 해당 단원에 대한 작은 코드 작성 문제와 공개된 예시
- **Practice Exercise:** 단원 복합 문제와 여러 입력·경계값 자동 테스트
- **Challenge:** 스스로 자료구조·알고리즘 설계/구현, 난도 별 학습 목표
- **Capstone:** 새로 배운 내용을 묶어 사용하는 완성형 프로젝트

## 시제품의 구현 범위

현재 시제품에는 C 16개 샘플, Rust 1개, 자료구조 1개, 알고리즘 1개만 작성되어 있음. C 함수 단원은 상세 원고·정적 호출 도식·퀴즈·전체 프로그램형 `clamp` 실습을 연결했다. 함수 본문만 제출하는 실습은 `clamp`, 배열 최댓값, 문자열 문자 세기, 용량 제한 문자열 길이, 구조체 학생 점수 갱신, 구조체 배열 학번 검색, 구조체 배열 안정 정렬 일곱 개다. 배열 실습은 길이·출력 포인터·실패 시 출력 보존을, 문자열 실습은 널 종료·읽기 경계·`const`·종료 문자 제외 계약을 검사한다. 용량 제한 실습과 `fgets` 논리 줄 실습에 이어 `strtol` 정수 입력 실습이 숫자 없음·잔여 문자·`ERANGE`·정확한 63바이트와 초과 줄을 분리한다. 구조체 갱신 실습은 값 복사와 주소 전달, 화살표 멤버 접근, 유효 점수와 덧셈 전 범위 검사, 실패 시 객체 전체 보존을 연결한다. 구조체 배열 검색은 배열 매개변수와 별도 길이, `[0, count)`, 점 멤버 접근, 첫 일치와 실패 시 출력 보존을 연결한다. 후속 안정 정렬은 레코드 전체 이동, 동등 키 순서, 빈 범위와 관계 비교로 signed overflow를 피하는 계약을 연결한다. 다중 파일 실습은 `main.c`·`functions.c`·`functions.h`를 나누어 컴파일·링크한다. 대규모 본문/문제 생성은 별도 후속 작업이 필요하다.

현재 진도 화면은 이론 읽기, 퀴즈 통과, C 실습 통과, 복습 필요, 전체 숙달을 서로 다른 상태로 계산한다. 이는 교육과정 완성도를 뜻하지 않으며, 자동 채점이 없는 트랙은 실습·숙달을 완료로 표시하지 않는다.

19개 시범 연습은 Concept/Practice, 언어, 선수 단원, 개념, 채점기, 공개 예시 메타데이터를 갖는다. 실제 채점 가능한 C 문제는 전체 프로그램 입출력형 8개, 함수 직접 호출형 7개, 다중 파일형 1개다. 함수형은 사용자 소스와 서버 전용 하네스를 별도 번역 단위로 링크해 반환값과 불필요한 출력 부작용을 검사한다. 배열 문제는 음수·중복·한 원소·`INT_MIN`/`INT_MAX`와 세 가지 잘못된 입력 계약을, 문자열 문자 세기 문제는 빈 문자열·대소문자·없는 문자·`target == '\0'`·`NULL` 계약과 출력 보존을 포함한다. 용량 제한 문자열 문제는 정확한 마지막 칸, 범위 밖 종료 문자, 비종료 버퍼, 용량 0과 포인터 오류를 포함한다. 구조체 갱신 문제는 11개 사례로 정상·0/100 경계·0 변화량·범위 밖 결과·잘못된 현재 상태·`NULL`·`INT_MIN`/`INT_MAX` 변화량을 검사하고 실패 시 id와 score를 모두 보존한다. 구조체 배열 검색 문제는 11개 사례로 첫·중간·마지막·단일 원소, 미발견, 중복의 첫 위치, 세 가지 잘못된 인수와 `INT_MIN` 학번을 검사하며 모든 실패에서 유효한 출력 객체를 보존한다. 구조체 배열 정렬 문제는 11개 사례로 정렬·역순·단일·중복·동등 키·정수 극값·음수 키·빈 범위·양수 길이의 `NULL`을 구분하며 구조체 전체 이동과 안정성을 검사한다. `fgets` 문제는 9개 입력으로 조각 누적과 줄/EOF 경계를, `strtol` 문제는 16개 입력으로 부호·공백·숫자 없음·잔여 문자·양방향 범위 초과·첫 줄·즉시 EOF·63/64바이트 경계를 검사한다. 일반 파이프로 재현하기 어려운 입력 오류 분기의 실제 발생까지 검증했다고 주장하지 않는다. 다중 파일형은 고정 파일 계약과 크기를 먼저 검증하고 두 `.c` 파일을 헤더 검색 경로와 함께 컴파일한다. 컴파일 실패는 원문을 보존하면서 누락 헤더·선언/정의 충돌·미정의 참조·중복 정의·일반 컴파일/링크 오류로 구분하여 재제출 때 확인할 항목을 안내한다. Rust 채점은 아직 구현하지 않았다.
