## 퀴즈 및 코딩 문제 정책

- **Concept Check:** 2~5문항 짧은 퀴즈, 직접 판단하는 문제
- **Concept Exercise:** 해당 단원에 대한 작은 코드 작성 문제와 공개된 예시
- **Practice Exercise:** 단원 복합 문제와 여러 입력·경계값 자동 테스트
- **Challenge:** 스스로 자료구조·알고리즘 설계/구현, 난도 별 학습 목표
- **Capstone:** 새로 배운 내용을 묶어 사용하는 완성형 프로젝트

## 시제품의 구현 범위

현재 시제품에는 C 21개 샘플, Rust 1개, 자료구조 1개, 알고리즘 1개만 작성되어 있음. C 함수 단원은 상세 원고·정적 호출 도식·퀴즈·전체 프로그램형 `clamp` 실습을 연결했다. 함수 본문만 제출하는 실습은 `clamp`, 배열 최댓값, 문자열 문자 세기, 용량 제한 문자열 길이, 구조체 학생 점수 갱신·배열 검색·안정 정렬·첫 위치 이진 탐색, 동적 학생 배열 생성/해제, `realloc` 용량 확장, 기하급수 push 열한 개다. 배열·문자열·입력 실습은 길이·출력 포인터·널 종료·읽기 경계·`fgets` 조각·`strtol` 오류를 구분한다. 구조체 실습은 값 복사와 주소 전달, 레코드 전체 이동, 안정성, 정렬 전제와 중복의 첫 위치를 연결한다. 동적 배열 생성은 크기 검사·소유권·할당 실패를, 용량 확장은 임시 포인터·새 슬롯 초기화·실패 보존을 다룬다. 후속 push는 빈 슬롯에서 무할당, 0→4와 이후 두 배 성장, 원소 수/바이트 수 오버플로, `reserve_students` 함수 합성과 성공 뒤 길이 공개를 연결한다. 기본 다중 파일 실습은 `main.c`·`functions.c`·`functions.h`를 나누어 컴파일·링크하고, 학생 명부 Mini Project는 `main.c`·`student.c`·`student.h`로 안정 정렬과 첫 위치 검색을 조립한다. 대규모 본문/문제 생성은 별도 후속 작업이 필요하다.

현재 진도 화면은 이론 읽기, 퀴즈 통과, C 실습 통과, 복습 필요, 전체 숙달을 서로 다른 상태로 계산한다. 이는 교육과정 완성도를 뜻하지 않으며, 자동 채점이 없는 트랙은 실습·숙달을 완료로 표시하지 않는다.

24개 시범 연습은 Concept/Practice, 언어, 선수 단원, 개념, 채점기, 공개 예시 메타데이터를 갖는다. 실제 채점 가능한 C 문제는 전체 프로그램 입출력형 8개, 함수 직접 호출형 11개, 다중 파일형 2개다. 함수형은 사용자 소스와 서버 전용 하네스를 별도 번역 단위로 링크해 반환값과 불필요한 출력 부작용을 검사한다. 배열 문제는 음수·중복·한 원소·정수 극값과 잘못된 입력 계약을, 문자열 문제는 빈 문자열·대소문자·종료 경계·`NULL`과 출력 보존을 포함한다. 구조체 갱신·검색·정렬·이진 탐색은 상태 보존, 레코드 전체 이동, 안정성, 정렬 전제와 첫 위치 정책을 각각 11~12개 사례로 검사한다. 동적 학생 배열 생성은 12개 사례로 0개·크기 오버플로·할당 실패·초기화·해제를, 용량 확장은 13개 사례로 불변식·성장 정책·오버플로·실패 보존·새 슬롯 초기화를 검사한다. push는 17개 사례로 여유 슬롯·0→4·두 배 성장·반복 성장·정수 극값 레코드·NULL·불변식·두 단계 오버플로·예약 실패를 검사하며 검증된 reserve 함수 재사용을 요구한다. 제한된 `--wrap=malloc/free/realloc` 링커 하네스와 reserve 실패 주입은 계약을 재현하지만 공개 실행 격리를 제공하지 않는다. `fgets` 문제는 9개 입력으로 조각 누적과 줄/EOF 경계를, `strtol` 문제는 16개 입력으로 부호·공백·숫자 없음·잔여 문자·양방향 범위 초과·첫 줄·즉시 EOF·63/64바이트 경계를 검사한다. 학생 명부의 10개 사례는 정렬 전/후, 안정 중복, 첫 위치, 미발견, 빈 입력, 정수 경계와 잘못된 입력을 검사한다. 다중 파일형은 고정 파일 계약과 크기를 먼저 검증하고 두 `.c` 파일을 헤더 검색 경로와 함께 컴파일한다. 컴파일 실패는 원문을 보존하면서 누락 헤더·선언/정의 충돌·미정의 참조·중복 정의·일반 컴파일/링크 오류로 구분한다. Rust 채점은 아직 구현하지 않았다.

2026-10-14 교차 감사 후속 작업으로 `c-types`와 `c-pointer`의 이식 가능한 입력 범위를 고정했고, 이어 `push_student`의 기하급수 성장 계약을 추가했다. 반복문의 n=1과 배열 첫 원소 최대·중복/0·대표 정수 경계를 포함해 현재 실제 GCC 사례는 189개다. 범위 밖 값·변환 실패·추가 토큰·조기 EOF는 두 계산 입문 문제의 채점 대상이 아니며 강건한 입력은 후속 `fgets`·`strtol` 단원에서 다룬다. 첫 기초 단원 `c-hello`는 전처리→번역→링크→실행, 표준 `main`, 문자열·개행, 출력 오류와 종료 상태를 독립 원고·정적 도식·실제 컴파일 예제로 확장했다. `c-types`도 객체·초기화·대입·수치 한계·변환 시점·입출력 계약을 21절 화면과 독립 원고, 실제 GCC로 검사하는 두 완성 프로그램으로 확장했다. `c-loops`는 22절 화면·독립 원고·반복 흐름/불변식 SVG·두 컴파일 예제로 조건식·분기·반복 상태·종료·최소 long 누산 범위를 확장했으며 0회·1회·상한과 마지막 항 누락/누산값 초기화 오답을 구분한다. `c-array`는 24절 화면·독립 원고·반열린 인덱스 도식·두 컴파일 예제로 객체·초기화·용량/사용 길이·sizeof·배열 매개변수·최댓값 불변식을 확장했고 기존 함수형 문제와 역할을 구분했다. `c-pointer`도 29절 화면·독립 원고·별칭/재대입 정적 도식·세 컴파일 예제로 주소/값·NULL·수명·배열/길이·호출자 변경과 실패 보존을 확장했다. 첫 다섯 기초 단원의 상세화는 전체 C 교과서 완성이 아니며 함수의 범위/저장기간·재귀, 파일 입출력, 자료구조/알고리즘 전체 과정은 추가 집필·검수가 필요하다. 상세 감사 결과는 [`C_EXERCISE_AUDIT.md`](./C_EXERCISE_AUDIT.md)에 기록했다.
