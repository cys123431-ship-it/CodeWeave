# GitHub 저장소 안내

현재 공식 개발 저장소: https://github.com/cys123431-ship-it/CodeWeave

소스코드는 `main` 브랜치에 저장합니다.

## 로컬에서 실행

```bash
git clone https://github.com/cys123431-ship-it/CodeWeave.git
cd CodeWeave
npm start
```

Node.js 20+가 필요하며 C 코딩 자동 채점에는 GCC가 필요합니다. **신뢰하는 개인 코드만 로컬에서 실행**하세요. 이 채점 서버는 격리되지 않아 인터넷에 배포해서는 안 됩니다.

## 변경 사항 관리

기능을 개발할 때는 새 브랜치에서 코드를 수정하고 테스트한 뒤 검토하여 main에 반영합니다. 새 교재 기반 콘텐츠는 저작권과 기술 정확성을 검토합니다.

## 공개 웹사이트 배포

GitHub 저장소가 만들어진 것과 웹사이트가 배포된 것은 별도 작업입니다. 정적 웹사이트를 배포해도 브라우저에서 실제 C 코드를 컴파일하는 자동 채점 기능은 작동하지 않으며 안전한 서버가 별도로 필요합니다.
