# 교재 참고 원칙과 교육 콘텐츠 제작 기준

## 제공된 두 교재

1. 천인국, 『쉽게 풀어쓴 C언어 Express』 개정 4판, 2022년 인쇄본 PDF(사용자 업로드). `c언어 압축 (1)(1).pdf`
2. Brian W. Kernighan / Dennis M. Ritchie, *The C Programming Language*, 2nd ed. (사용자 업로드). `C_Programming.pdf`

## 교재 활용 범위

『쉽게 풀어쓴 C언어 Express』의 그림+단계적 설명, 중간 점검, Q&A, Summary, Exercise, Programming, Mini Project **교육적 구성**을 우선 참고한다. K&R은 문법과 의미의 정확성 확인용으로 참고한다. 단원에서는 출처가 되는 **주제와 장**을 기록하되, 원문 문장·도표·캡처 이미지를 복사하지 않는다.

이번 초기 단원의 내용은 책의 모든 페이지를 완독·대조한 최종 통합본이 아니라 **별도 집필한 샘플**이다. 최종 교과서형 원고를 제작하려면 전체 PDF의 장·절별 주제·예제·실습을 개별 확인해야 한다.

## 학습 원고 원칙

1. 정의 → 필요한 이유 → 비유/표/그림 → 코딩 예제 → 실수 포인트 → 확인 퀴즈 → Exercism식 문제 → 경계 입력을 테스트
2. 가능한 현대적인 C11 예제 사용. K&R(1988) 고전 코드와 현대적인 규범이 다르면 차이 설명
3. 각 문제의 입출력 형식, 전제조건, 오답 이유를 명확하게 표시
4. 그림은 독자적으로 SVG 등으로 제작하고 원본 이미지 퍼가기를 금지
5. 개인용 PDF 분석과 불특정 다수 대상 사이트에 교재를 배포하는 것은 별개로 취급

## 교재의 확인된 구성 예시

- Express: 프로그래밍 개념/환경/C언어 구조/변수/수식과 연산자/조건문/반복문/함수/배열/포인터/문자·문자열/구조체/표준 입출력과 파일 등 다양한 장
- K&R: 튜토리얼 소개, 자료형과 연산자, 제어 흐름, 함수와 프로그램 구조, 포인터와 배열, 구조체, 입출력, UNIX 시스템 인터페이스

표준 문서 참고: ISO C11 기반 일반 학습 내용은 실제 컴파일러 동작으로 추가 검증한다.

2026-10-11 후속 확인: 두 개인 참고 PDF를 로컬에서 가져와 표지까지 확인했습니다(Express 개정4판 750쪽, K&R 2판 288쪽). 파일은 스캔 이미지이며 전체 목차/본문 대조는 미실시입니다. PDF와 표지 이미지는 공개 저장소에 포함하지 않았습니다.

2026-10-14 현재 실행 확인: 제공된 K&R PDF는 288쪽 메타데이터와 첫 페이지 렌더링을 다시 확인했다. 현재 제공된 Express 파일은 XRef·stream·trailer가 손상된 15,179,776바이트 파일이라 Poppler로 페이지 수나 본문을 읽지 못했다. 따라서 이번 `c-hello`·`c-types`·`c-loops` 확장은 Express를 읽었다고 전제하지 않고 독자 작성했으며, 두 PDF 어느 쪽의 본문·그림·상용 문제도 복제하지 않았다.

2026-10-14 14시 후속 확인: K&R 파일의 288쪽 메타데이터와 표지를 다시 확인했다. 현재 같은 경로의 Express 파일 크기는 5,950,976바이트로 앞선 확인과 다르며 XRef/endstream/trailer 오류로 여전히 읽지 못했다. 이번 c-array 확장도 독자 작성하고 N1570의 배열·초기화·sizeof·매개변수 의미를 검토했으며 교재 전체 본문 대조를 주장하지 않는다.

2026-10-14 15시 후속 확인: 두 로컬 PDF의 현재 상태를 다시 확인했다. K&R은 288쪽 메타데이터·표지 렌더링 확인에 성공했고 Express는 5,950,976바이트 파일의 XRef/endstream/trailer 오류로 읽지 못했다. c-pointer 원고·도식·예제·연습은 독자 작성했으며 N1570으로 수명·NULL·역참조·배열 경계·주소 출력 의미를 검토했다. 어떤 책의 전체 본문 대조나 원문 복제도 주장하지 않는다.
