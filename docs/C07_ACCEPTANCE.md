# C07 제한 범위 인수 — 소유 스트림 한 바이트 읽기

인수 검토: 2026-10-20 17:56 KST. 개발 단원 C07의 한 바이트 계약을 대상으로 한다.

## 전달 범위

- C05의 빌린 FILE과 달리 유효 인수 검사 후 소유권을 받는 read_owned_byte를 구현한다.
- 반환1은 읽기와 닫기가 성공한 한 바이트, 반환0은 정상 EOF, 반환-1은 오류다.
- 성공1일 때만 out_byte를 공개한다. EOF·오류에서는 기존 출력 바이트를 보존한다.
- 기존 ferror는 다시 읽지 않고 EIO 정책으로 처리한다. 새 읽기 오류는 즉시 errno를 저장하며 진단0이면 EIO를 사용한다.
- 유효 호출의 읽기 성공·EOF·오류 모두 fclose를 한 번 호출한다. 읽기와 닫기 동시 실패에서는 첫 읽기 진단을 보존한다.
- NULL·같은 출력 객체는 읽기/닫기/출력 변경 전 거부한다. 유효 스트림과 서로 다른 살아 있는 쓰기 가능한 int 객체는 호출자 전제다.
