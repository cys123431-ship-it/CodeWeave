# CodeWeave

## 소개

“교과서처럼 깊게 배우고, Exercism처럼 직접 풀다”를 목표로 하는 한국어 C·Rust·자료구조·알고리즘 통합 학습 PWA입니다.

이론 → 예제 → 개념 확인 → 코드 작성 → 실제 테스트 → 오류 수정 → 재제출 → 숙달 → 다음 단원을 연결합니다.
독자 작성 설명·정적 SVG 도식·실습을 사용하며 AI 멘토와 런타임 애니메이션은 만들지 않습니다.
현재 v0.1은 학습 흐름을 검증하는 초기 버전이며 전체 교과서·문제 은행의 완성본은 아닙니다.

## 빠른 시작

Node.js 20 이상과 PATH에서 실행 가능한 GCC를 준비하고 저장소 폴더에서 실행하세요.
일반 실행에 Node 패키지 설치는 필요하지 않습니다.

```bash
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.
반복 제출 연습장은 http://127.0.0.1:4173/workbench.html 입니다.

```bash
npm test
```

브라우저 검사 설치·실행과 자세한 환경 안내는 [로컬 개발 안내](docs/LOCAL_DEVELOPMENT.md)를 참고하세요.

## 기능 요약

| 트랙 | 단원 수 | 로컬 자동 채점 문제 수 |
|---|---:|---:|
| C언어 | 23 | 23 |
| Rust | 1 | 0 |
| 자료구조 | 2 | 1 |
| 알고리즘 | 1 | 0 |

- 총 27개 단원입니다. 자료구조의 연결 리스트 검색은 C 함수형으로 실제 채점합니다. Rust·알고리즘과 자료구조 스택은 아직 미채점 샘플입니다.
- [D01 원고](content/ds/01-linked-list.md)는 계약 준비 시점의 기록을 포함합니다. 현재 학습 화면·API 연결 상태와 검증 근거는 [로드맵](docs/ROADMAP.md)·[최근 일지](docs/DEVELOPMENT_LOG.md)를 확인하세요.
- C는 전체 프로그램·함수 직접 호출·다중 파일 제출을 GCC로 채점합니다. 문제별 사례·경계값은 [C 문제 감사](docs/C_EXERCISE_AUDIT.md)에 모았습니다.
- 단원별 설명·정적 도식·예제·개념 퀴즈와 코드 초안 저장을 제공합니다.
- 최근 10회 제출 확인·코드 복원·재제출, 이론/퀴즈/실습/복습/숙달 상태 구분을 지원합니다.
- 모든 트랙의 진도·초안·제출 이력을 JSON으로 통합 백업/복원하며 기존 v1 백업도 읽습니다.
- 반응형 화면과 정적 콘텐츠 캐시를 제공합니다. 설치·오프라인 검증 범위는 아래 제한을 확인하세요.

## 꼭 확인할 제한

- 로컬 서버는 신뢰하는 본인의 C 코드만 실행하는 개발 도구입니다. 실행 격리·샌드박스가 아니므로 공용 네트워크에 공개하지 마세요.
- Linux/macOS의 시간·출력·프로세스 그룹·자원 제한은 격리를 대신하지 않습니다. 예산·설정 실패 처리·권한 예외는 [로컬 개발 안내](docs/LOCAL_DEVELOPMENT.md)에 있습니다.
- Windows에서는 POSIX 프로세스 그룹과 CPU·가상 메모리·파일 크기·프로세스 수 제한이 적용되지 않습니다. 벽시계·출력 제한과 직접 자식 종료만 적용됩니다.
- 코드 상한은 JavaScript 문자열 25,000단위, JSON 본문은 UTF-8 104,096바이트입니다. 활성 컴파일 경고는 실패로 처리합니다.
- 정적 호스팅에서는 단원·퀴즈·작성·저장은 가능하지만 GCC 자동 채점은 실행되지 않습니다.
- 백업 복원은 대상 현재 데이터를 교체합니다. 먼저 최신 백업을 저장하세요. 같은 문제의 다중 탭 편집은 마지막 저장이 적용됩니다.
- CI Chromium의 390px·오프라인 검사는 Windows·Android·태블릿 실기기나 PWA 설치 검증을 대신하지 않습니다.
- 교재 PDF 원본과 대량 본문은 포함하지 않으며 교육 콘텐츠는 독자 작성합니다.
