## 단원 개요 — 함수를 왜 나누는가

프로그램이 커지면 입력, 계산, 출력이 한 함수에 뒤섞이기 쉽습니다. 함수를 사용하면 하나의 동작에 이름을 붙이고, 호출하는 쪽은 **무엇을 할지**, 함수 안은 **어떻게 할지**에 집중할 수 있습니다. 같은 계산을 재사용할 수 있고, 오류가 생겼을 때 검사할 범위도 줄어듭니다.

이번 단원에서는 값 하나를 지정한 범위 안으로 제한하는 `clamp` 함수를 중심으로 선언, 정의, 호출, 값 전달을 연결합니다.

## 1. 선언, 정의, 호출은 서로 다른 역할을 한다

함수 **선언**은 이름, 반환형, 매개변수의 자료형을 컴파일러에 알립니다. 함수 원형(prototype)은 호출 식을 검사할 수 있게 하는 계약입니다.

```c
int clamp(int value, int low, int high);  // 선언
```

함수 **정의**에는 실제로 수행할 명령문이 들어갑니다.

```c
int clamp(int value, int low, int high) { // 정의
    if (value < low) return low;
    if (value > high) return high;
    return value;
}
```

함수 **호출**은 인수를 전달해 동작을 실행하고 반환값을 받습니다.

```c
int limited = clamp(15, 0, 10);          // 호출, 결과는 10
```

선언과 정의의 자료형이 다르면 올바른 계약이 아닙니다. 선언만 있고 실제 정의가 링크 대상에 없다면 보통 링크 단계에서 정의를 찾지 못했다는 진단이 나옵니다.

## 2. 완성 예제와 실행 결과

다음은 이 단원의 코딩 연습과 같은 형태의 완성 프로그램입니다. `low <= high`인 입력을 전제로 합니다.

```c
#include <stdio.h>

int clamp(int value, int low, int high);

int main(void) {
    int value, low, high;

    if (scanf("%d%d%d", &value, &low, &high) != 3) {
        return 1;
    }

    printf("%d\n", clamp(value, low, high));
    return 0;
}

int clamp(int value, int low, int high) {
    if (value < low) return low;
    if (value > high) return high;
    return value;
}
```

입력:

```text
15 0 10
```

실행 결과:

```text
10
```

`main`은 세 정수를 읽어 `clamp(15, 0, 10)`을 호출합니다. `15 > 10`이므로 `clamp`는 `high`의 값 10을 반환하고, `printf`가 그 결과를 출력합니다.

## 3. 인수, 매개변수, 반환값

호출 식의 `15`, `0`, `10`은 **인수**이고, 함수 정의의 `value`, `low`, `high`는 **매개변수**입니다. 호출이 시작되면 각 인수의 값을 대응하는 매개변수로 전달합니다. `return`은 현재 함수 실행을 끝내고 호출 지점으로 값을 돌려줍니다.

반환형이 `void`가 아닌 함수가 정상적으로 끝까지 도달한다면 필요한 값을 반드시 반환하도록 작성해야 합니다. 특히 반환값을 사용하는 호출에서 값 없이 끝나는 경로는 정의되지 않은 동작을 일으킬 수 있습니다.

## 4. C의 함수 인수는 모두 값으로 전달된다

정수 변수를 인수로 넘기면 그 값이 매개변수에 복사됩니다. 함수 안에서 매개변수를 바꿔도 호출자의 변수는 바뀌지 않습니다.

```c
void set_zero(int value) {
    value = 0;  // 복사본만 변경한다.
}
```

호출자의 객체를 바꾸려면 그 객체를 가리키는 포인터를 전달하고 역참조합니다.

```c
void set_zero(int *value) {
    *value = 0;
}

int n = 7;
set_zero(&n);   // n은 0이 된다.
```

이를 별도의 “주소 전달 방식”이라고 오해하기 쉽지만, C에서는 여기서도 **포인터 값**이 매개변수에 복사됩니다. 복사된 포인터가 같은 `n` 객체를 가리키므로 `*value`를 통해 호출자의 객체를 수정할 수 있는 것입니다.

## 5. 지역 변수의 범위와 수명

함수의 매개변수와 블록 안에서 선언한 자동 지역 변수는 그 블록에서 이름을 사용할 수 있습니다. 일반적인 자동 지역 객체의 수명은 해당 블록 실행이 끝날 때 종료됩니다.

```c
int square(int x) {
    int result = x * x;
    return result;          // 값을 반환하므로 안전하다.
}
```

이 예제는 `x * x`가 `int`의 표현 범위 안이라는 전제입니다. 그 전제에서 `result`의 값을 복사해 반환하는 것은 수명 측면에서 안전합니다. 반면 자동 지역 변수의 주소를 반환한 뒤 역참조하면 이미 수명이 끝난 객체에 접근하게 되므로 정의되지 않은 동작입니다.

## 6. 배열 매개변수에는 길이 정보가 들어 있지 않다

함수 매개변수에서 `const int values[]`는 `const int *values`로 조정됩니다. 이 매개변수만으로 원소 개수를 알 수 없으므로 길이를 별도 인수로 전달합니다.

```c
long long sum_array(const int values[], int count) {
    long long sum = 0;
    for (int i = 0; i < count; ++i) {
        sum += values[i];
    }
    return sum;
}
```

이 함수는 `count >= 0`이고 `values`가 적어도 `count`개의 유효한 `int` 원소를 가리킨다는 전제가 필요합니다. `const`는 이 포인터를 통해 원소를 수정하지 않겠다는 계약을 표현합니다. 반환형을 `long long`으로 정해도 모든 가능한 입력의 합이 항상 표현 범위 안에 든다는 보장은 별도로 확인해야 합니다.

## 7. 헤더와 여러 소스 파일로 확장하기

프로그램이 커지면 함수 선언은 `functions.h`, 정의는 `functions.c`, 호출 코드는 `main.c`로 나눌 수 있습니다. 헤더에는 중복 포함 방지 장치를 두고, 선언과 정의의 자료형을 일치시킵니다. 여러 `.c` 파일을 각각 컴파일한 뒤 함께 링크해야 실행 파일에 정의가 포함됩니다.

현재 브라우저의 `clamp` 연습은 하나의 소스 파일을 채점합니다. 다중 파일형 채점은 별도의 인터페이스와 테스트 격리를 갖춘 뒤 확장합니다.

## 흔한 오류

- 호출 전에 올바른 선언이 보이지 않는다: 컴파일러가 인수와 반환형을 정확히 검사할 수 있도록 원형을 제공해야 합니다.
- 선언과 정의의 매개변수 자료형이 다르다: 같은 함수의 계약이 충돌합니다.
- 정의를 링크하지 않는다: 선언은 있지만 함수 몸체를 찾지 못해 링크가 실패할 수 있습니다.
- `int` 반환 함수의 일부 경로에 `return`이 없다: 반환값을 사용하면 정의되지 않은 동작이 될 수 있습니다.
- 지역 변수의 주소를 반환한다: 함수가 끝난 뒤 그 객체의 수명이 종료됩니다.
- 배열 길이를 추측한다: 배열 매개변수에는 전체 배열의 크기 정보가 보존되지 않습니다.
- `f(i++, i++)`처럼 평가 순서에 의존한다: 같은 객체에 대한 순서 없는 변경이 생기는 식은 작성하지 않습니다.

## 핵심 요약

- 선언은 함수의 자료형 계약, 정의는 실제 동작, 호출은 인수를 주고 실행을 요청하는 식입니다.
- 인수의 값은 매개변수에 전달되며 `return` 값은 호출 지점으로 돌아갑니다.
- C의 함수 인수는 포인터를 포함해 모두 값으로 전달됩니다.
- 포인터로 같은 객체를 가리키면 역참조를 통해 호출자의 객체를 수정할 수 있습니다.
- 자동 지역 객체의 주소는 그 수명이 끝난 뒤 사용할 수 없습니다.
- 배열 매개변수와 유효한 원소 수를 함께 전달해야 반복 경계를 정할 수 있습니다.

## 개념 확인

함수 원형의 가장 중요한 역할은 함수 이름, 매개변수 자료형, 반환형을 컴파일러에 알려 호출을 검사하게 하는 것입니다. 원형이 함수 몸체를 실행하거나 외부 입력을 자동 검증해 주는 것은 아닙니다.
