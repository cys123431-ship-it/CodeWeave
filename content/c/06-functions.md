# C언어 심화 06 — 함수를 정의하고 나누는 이유

> 독자 집필 초안 · 학습 목표: 선언과 정의를 구분하고, 인수 전달과 반환값을 설명하며, 작은 기능을 함수로 분리한다.

## 1. 함수를 사용하는 이유

프로그램에 같은 계산이 여러 번 등장하면 코드를 복사하기보다 이름 붙은 함수로 분리하는 것이 좋습니다. 호출하는 쪽은 **무엇을 계산할지**만 결정하고, 함수 안은 **어떻게 계산할지**를 담당합니다. 이렇게 나누면 오류를 찾을 때 검사 범위를 줄일 수 있고 같은 동작을 여러 곳에서 재사용할 수 있습니다.

예를 들어 정수 두 개 중 큰 값을 선택하는 기능은 다음처럼 작성할 수 있습니다.

```c
int larger(int a, int b) {
    return a > b ? a : b;
}
```

`larger(3, 8)`을 호출하면 매개변수 `a`에는 3, `b`에는 8이 전달되고 결과로 8이 반환됩니다. `return`은 함수를 종료하고 호출 지점으로 값을 돌려줍니다.

## 2. 선언, 정의, 호출

- **선언:** 함수의 이름과 매개변수, 반환형을 컴파일러에 알립니다.
- **정의:** 실제 동작을 중괄호 안에 작성합니다.
- **호출:** 함수 이름 뒤에 인수를 적어 실행을 요청합니다.

```c
#include <stdio.h>

int larger(int a, int b);  // 선언

int main(void) {
    printf("%d\n", larger(3, 8)); // 호출
    return 0;
}

int larger(int a, int b) {  // 정의
    return a > b ? a : b;
}
```

출력은 `8`입니다. 선언과 정의가 서로 다른 파일에 있을 때는 헤더에 선언을 두고, 구현은 별도의 `.c` 파일에 작성할 수 있습니다.

## 3. 값 전달과 주소 전달을 구분하기

C에서 함수 인수는 **값으로 전달**됩니다. 정수 인수를 받은 함수가 자신의 매개변수를 변경해도 호출자의 정수 변수는 그대로입니다. 호출자 변수를 변경하려면 주소를 가리키는 포인터를 인수로 전달하고, 그 포인터를 통해 값을 수정해야 합니다.

```c
void add_one(int *value) {
    ++(*value);
}
```

`int n = 4;` 다음에 `add_one(&n);`을 호출하면 `n`은 5가 됩니다. 여기서도 전달되는 것은 주소를 나타내는 **포인터 값**이며, 포인터를 역참조해 호출자 객체를 수정하는 것입니다.

## 4. 배열을 받는 함수

배열을 함수에 넘기면 매개변수의 배열 표기는 해당 원소를 가리키는 포인터 매개변수로 조정됩니다. 따라서 배열 원소의 개수는 별도 인수로 전달하는 편이 좋습니다.

```c
long long sum_array(const int values[], int n) {
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        sum += values[i];
    }
    return sum;
}
```

이 함수는 `n >= 0`이고 `values`가 적어도 `n`개의 유효한 원소를 가리킨다고 가정합니다. `const`는 함수가 이 포인터를 통해 원소를 수정하지 않겠다는 의도를 나타냅니다. 반환형을 `long long`으로 해도 극단적으로 큰 합에서는 오버플로를 별도로 고려해야 합니다.
